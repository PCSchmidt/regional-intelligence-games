# Cable Ship prototype: assets and notices

All deck, ROV, cable, net, rock, terrain, survey-plot and particle geometry,
materials and textures are generated by this project's scripts. There are no
downloaded models, photographs, map tiles, audio tracks or external fonts.
The UI uses Godot's bundled default font. No project-wide reuse license has
been selected for original code/content.

Real regional place names provide context only. The ship, cable route,
incident and seabed are fictional. The 420 m depth and terrain are authored,
not measurements of Bashi Channel bathymetry. Observation text is authored
scenario evidence; this first-pass geometry does not reproduce every described
micro-detail. No historical event, vessel identity or intent is asserted.
